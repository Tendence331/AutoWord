# AutoWord

**Домашнее задание 14.10.1**

# ЗАДАЧА: В качестве итогового задания вам необходимо реализовать программу, выполняющую автодопление введенного слова по изначально заданному словарю.
То есть, вам необходимо построить дерево, которое будет словарем, а затем выполнить проверку и предложить подходящие варианты слов по введенной части. Дополнение можно реализовываться как по нажатию какой-либо клавиши, так и любым другим способом. После нажатия программа не должна завершаться и ждать нового ввода от пользователя.

# Реализация методов

1. Метод сборки слова (обход DFS) - void collectWord(Trie* node, std::string key, std::string* res, int& count)
    Функция проверяет что узел не пустой
    Проверяет если найден конец слова
    Добавляет ключ в массив res (результат)
    Проходит по всему алфавиту и рукурсивно продолжает обход

2. Поиск узла по ключу - Trie* findNode(Trie* root, std::string& key) (аналогично поиску search в модуле, только возвращает значение не bool)
    Начинаем с корня дерева
    Проходим по каждому символу ключа
    Получаем индекс символа
    Если нет узла по индексу - значит он отсутствует возвращает nullptr
    Переходим к слежующему узлу
    Возвращаем наш узел

3. Главная функция автодополнения - void getPrefix(Trie* root, std::string key)
    Находим наш узел
    Проверяем найден ли наш узел
    Объявление массива и счетчика
    Вызов первого метода - поиск слов начинающихся с префикса
    Вывод слов - подсказок
